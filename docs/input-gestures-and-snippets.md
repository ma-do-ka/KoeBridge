# 録音ジェスチャーとスニペット（Build 43）

「音声入力」設定の録音キーの下（「一般」からも変更可能）で操作方法とマウスボタンを選べます。初期設定はトグル、マウス割当なしです。

- **トグル**：押すたびに開始・確定を切り替えます。
- **ホールド**：押している間だけ録音し、離すと確定します。準備中に離すと取り消します。
- **ハイブリッド**：0.4秒未満の短い押下は録音を固定します。次に押すと確定します。0.4秒以上押した場合は離した時点で確定します。

マウスは中央ボタン（2）、サイドボタンの戻る（3）、進む（4）を割り当てられます。キーボードと同じ操作状態を共有するため、どちらからも開始・確定できます。マウス監視は入力監視の許可が必要です。クリックは一切消費せず、通常のクリックとしてもそのまま動作します。割当なしではマウスのイベントタップを作成しません。

右Commandなどの単独修飾キーも押下・解放の時点で動作します。別のキーと組み合わせる前の押下から録音が始まるため、普段使う修飾キーを割り当てる際は注意してください。既存の物理キー追跡と解放欠落時の確認は継続します。

「音声入力」の「スニペット」欄で追加・編集・削除します。例えば「メール締め」を「よろしくお願いいたします。山田」に置き換えられます。追加すると呼び出す言葉にフォーカスします。定型文への挿入ボタンは最後に編集した行（未編集なら先頭）を対象にします。

呼び出す言葉の完全一致をすべて置換します。長い呼び出し語から順番に処理し、同じ長さなら一覧順です。後のルールは先の置換結果にも適用されます。空白だけの呼び出し語は無視します。

- `{{DATE}}`：展開時の日付 `yyyy/MM/dd`
- `{{TIME}}`：展開時の時刻 `HH:mm`
- `{{CLIPBOARD}}`：展開時のクリップボードの文字列（文字列がなければ空文字）

日付と時刻は現在のカレンダー・タイムゾーンに従います。未知の `{{...}}` はそのまま残ります。クリップボード内のトークンは再解釈しません。

置換はAIを使わずローカルで決定的に処理します。スタイル・文脈処理後の最終結果を確定し、履歴保存・順序付き自動入力に渡す前に展開します。履歴には展開後の文章が残ります。抑止された録音、要確認の結果、自動入力オフ、無入力、失敗した録音は展開しません。入力時の追加のフォーカス・権限確認で送信を中止する場合はあります。

プライバシー：`{{CLIPBOARD}}` を含む定型文が実際に展開される瞬間にだけクリップボードを読みます。認識中・設定編集時・一致しない呼び出し語では読みません。クリップボードの内容やスニペットはログに記録しません。
