# ローカル認識エンジン

Appleのローカル認識は、macOSのバージョンに合わせて自動的に選ばれます。

- macOS 26以降: SpeechAnalyzer / SpeechTranscriber。
- macOS 15〜25: 従来のSFSpeechRecognizer。既存のオンデバイス認識をそのまま使います。

SpeechAnalyzerの起動に失敗した場合、その録音だけ新しいSFSpeechRecognizerに
自動的に切り替えます。キャンセル時は切り替えません。診断ログが有効な場合、
エンジン選択と切り替えを記録します。Gemini失敗時のローカル復旧でも同じ自動選択を
使いますが、その復旧処理では起動失敗時の再切り替えは行いません。

SpeechAnalyzerは初回利用時など、必要な日本語の認識モデルをAppleから
ダウンロード・インストールすることがあります。その際はネット接続と待ち時間が
必要です。認識処理はMac内で行われます。モデルのインストール開始も診断ログに
記録します。

SpeechAnalyzerはSFSpeechRecognizer用の「音声認識」許可を要求しません。
マイクの許可は引き続き必要です。従来のSFSpeechRecognizerへの切り替え時は
音声認識の許可が必要です。録音後のローカル復旧では許可ダイアログを出さないよう、
従来エンジンを使う場合だけ事前の音声認識許可を確認します。

SpeechTranscriberには`progressiveLongDictation`がないため、ライブ音声の途中結果を
返す`progressiveTranscription`プリセットを使用します。確定したセグメントを連結し、
未確定の部分だけを更新します。入力終了後に結果ストリームが終了して初めて最終結果と
扱い、5秒以内に確定しない途中結果は自動入力しません。
