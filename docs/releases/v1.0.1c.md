# KoeBridge v1.0.1c — ログイン時の自動起動登録を改善

2026-11-05 / macOS 15以降 / ソースコード版

## 変更内容

- **ログイン項目の登録を試行**：設定 → 一般 → 起動と常駐 → 「ログイン時に自動起動」をONにすると、現在の登録状態を読み直して `SMAppService.mainApp.register()` によりKoeBridgeをmacOSへ登録する。
- **`.notFound` の操作不能を修正**：これまで「ログイン項目を認識できません」と表示された際、トグル自体が無効になっていた。macOSがサービスを見つけられない状態でも、ユーザーがONを選択すると一度登録を試行できるようにする。
- **macOSの承認はユーザーが行う**：登録後の状態が「承認待ち」なら、OSのログイン項目設定画面を自動で開く。ユーザーがそこで許可するまでは自動起動しない。
- **失敗時の案内**：登録できず `.notFound` / `.notRegistered` が続く場合は、画面に失敗を明示してmacOSの設定とKoeBridge.appのFinder表示への導線を出す。登録に失敗したのにONと見せない。
- **安全性**：設定を開くだけでは自動登録しない。ユーザーがトグルを操作したときだけ登録・解除する。権限の自動承認、外部スクリプトの設置、既存ログイン項目の無断削除、アプリ自体の移動は行わない。OSの実際の登録状態を再読み込みする。
- バージョン表示 `1.0.1c`、macOSの内部バージョン `1.0.1`、ビルド番号 `22`。

## macOSによる制約

AppleのSMAppServiceは `register()` によって登録できますが、**既にユーザーの承認がある場合など、macOS側で直ちに有効になる場合もあります**。必ず手動承認画面を出すことや、OSが見つけられないサービスを必ず登録できることは保証できません。macOSが登録を拒否したときは、アプリからOSの承認を強制しません。

## 更新方法

KoeBridgeをメニューバーから終了し、`~/KoeBridge` が公式Gitリポジトリの場合：

```bash
cd ~/KoeBridge
git switch main
git pull --ff-only origin main
bash scripts/verify_and_build.sh --open
/usr/libexec/PlistBuddy -c 'Print :KoeBridgeReleaseLabel' dist/KoeBridge.app/Contents/Info.plist
```

最後に `1.0.1c` と表示されれば該当ビルドです。設定 → 一般で「ログイン時に自動起動」をONにして、登録結果とmacOSの許可を確認してください。KoeBridgeの起動元が別のアプリコピーなら、登録するアプリが意図したものであるかFinderで確認してください。

## 検証範囲

- macOSのSwiftテスト、ポータブルテスト、公開ファイル監査、Releaseビルド、アプリ生成・署名検証をGitHub Actionsで実施。
- `.notFound` からの登録試行、登録済みの重複防止、承認待ちの表示、解除の条件をOS非依存の判定テストで検証。
- **実機のmacOSログイン項目へ追加されたこと・次回ログイン時の自動起動はCIだけでは確認できません**。利用者のMacで最終確認が必要です。

GitHub Releaseはソースコード配布です。Apple Developer IDで署名・公証済みのインストーラではありません。旧タグ `v1.0.1` と `v1.0.1b` は変更しません。
