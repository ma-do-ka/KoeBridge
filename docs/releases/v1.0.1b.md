# KoeBridge v1.0.1b — AIエージェント指示モード

2026-11-05 / macOS 15以降 / ソースコード版

## 変更内容

- **文字起こしスタイルを3択に変更**：「逐語」「読みやすく」「AIエージェント指示」
- **AIエージェント指示モード**：Gemini Liveの公式 `VERBATIM` を使い、言い直しや条件を削らずに文字起こし。ユーザーの登録用語を優先し、GitHub Actions・n8n・Python・SwiftUI・JSON・YAML・MCP・APIなどの補助辞書を追加（合計最大100語）
- **最小限の段落整理**：特定の指示の切り替わりに改行を入れるだけ。本文の単語・コマンド・URL・パス・数値は削除・置換しない。自動入力時の改行は誤送信防止のためスペースに変換され、履歴には改行が残る
- **過去の設定を維持**：以前の「話した内容を読みやすく整える」がONなら「読みやすく」、OFFなら「逐語」に移行。新スタイルが選択された後はその値を保存
- **ログイン時の自動起動**：設定→一般からON/OFF可能。macOSの実際のログイン項目状態と承認待ちを表示する。先行開発中だった1.0.1aの変更を本リリースに含める
- **バージョン表記**：「情報」画面に `1.0.1b / Build 21` を表示する。アプリ内部の `CFBundleShortVersionString` はApple規則に従い `1.0.1` のまま

## 技術的な制約

Gemini 3.5 Transcribe Liveの公式モードは `VERBATIM` と `SMART` のみ。AIエージェント指示はKoeBridgeが追加するユーザー向けスタイルであり、Gemini側に存在しない第3モードを送信しない。**発言内容の100%の正確性は保証できない**。特殊な記号、コマンド、ファイル名は認識後に確認してください。

二次的なLLM呼び出しや音声の再送信は追加しない。文字起こし完了後の自動入力と、入力先が変わった場合に安全のため中止する処理は従来どおり。macOSの音声認識許可・マイク権限はユーザーが管理する。

## 本番反映

メニューバーからKoeBridgeを終了後、GitHubの `main` を使う：

```bash
cd ~/KoeBridge
git switch main
git pull --ff-only origin main
bash scripts/verify_and_build.sh --open
/usr/libexec/PlistBuddy -c 'Print :KoeBridgeReleaseLabel' dist/KoeBridge.app/Contents/Info.plist
```

最後に `1.0.1b` が表示されれば該当ビルドです。現在アプリを別の場所から起動している場合は、その配置先の更新と起動元確認が必要です。
