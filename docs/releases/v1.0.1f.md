# KoeBridge v1.0.1f — メニューバーから履歴コピー

2026-11-06 / macOS 15以降 / ソースコード公開版 / Build 25

## 変更箇所・区分

- `Sources/KoeBridge/Main.swift`：既存の「認識履歴（直近10件）…」を、ホバーで開くネイティブの「認識履歴（直近10件）」サブメニューに**一部置換**。メニューの表示時に保存済み最新10件を取得。
- サブメニューに「番号・認識日時・文章の冒頭（44文字以内）」を表示。途中認識データは「［途中］」を付記。クリックした履歴の**全文**を、改行も保持してクリップボードへコピー。
- `Sources/KoeBridge/Windows.swift`：成功時「コピーしました / ⌘Vで貼り付けできます」、失敗時「コピーできませんでした」を約2.2秒表示する、フォーカスを取らない通知UIを**新規追加**。
- `Sources/KoeBridge/VoiceController.swift`：既存のコピー処理の真偽値を呼び出し元に返すだけの**一部変更**。
- `Sources/KoeBridgeCore/RecentHistoryMenuPolicy.swift` とテスト：安全なプレビュー整形と10件制限を**新規追加**。
- 従来の「認識履歴」ウィンドウはサブメニューの「履歴をすべて表示…」からそのまま利用可能。
- ローカルの履歴ファイル、音声認識、Gemini API、設定、OS権限、録音キー、アップデートの配布方式は**変更なし**。

## 動作

1. KoeBridgeのメニューバーアイコンをクリック。
2. 「認識履歴（直近10件）」にマウスを重ねるとサブメニューが開く。
3. 履歴の行を選ぶと全文がクリップボードにコピーされる。
4. コピー成功の表示を確認し、目的の入力欄にフォーカスして⌘Vで貼り付ける。

コピーはクリック操作時だけ実行され、メニューのホバーではクリップボードを変更しません。履歴がない場合は「保存された認識履歴はありません」と表示します。

## 検証と配布

macOS CIでSwift Testing、Portable自己テスト、Releaseビルド、署名、公開ファイル監査を実行します。ホバーと表示位置・多画面での操作、UIの通知タイミングは利用者Macで実機確認が必要です。正式な配布は従来どおり**ソースコードのみ**。自動インストール用の署名済みアプリはありません。
