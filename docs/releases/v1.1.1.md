# KoeBridge v1.1.1 — 処理の整理と不具合修正

2026-11-07（日本時間） / macOS 15以降 / Build 27

## ダウンロード

`KoeBridge-v1.1.1-macOS-universal-development.zip` は Apple Silicon・Intel 共通の開発版アプリです。公開後は、このリリースの Assets からダウンロードできます。`SHA256SUMS.txt` で ZIP の SHA-256 を照合できます。

**アドホック署名の開発版です。Developer ID 署名・Apple 公証はありません。** KoeBridge を終了してから既存アプリを退避し、展開したアプリへ置き換えてください。macOS の起動確認や、マイク・アクセシビリティ等の再許可が必要になる場合があります。

## リファクタリング

- **録音と確定処理。** 録音順の結果管理・直接入力の順序制御は `VoiceController` に残し、録音ごとの追加チェック、入力結果の説明、履歴・利用統計の保存を専用の型へ分離しました。
- **設定画面。** ナビゲーション、各設定ページ、共通の入力部品を分離しました。設定値と API キー下書きは明示的な Binding で受け渡します。既存の設定キー・選択肢・独立チェックボックスは維持しています。
- **Gemini 通信。** 同じ受信 JSON を用途ごとに再解析していた処理を、一つのフレーム解析へ集約しました。文字起こし、完了通知、セグメント識別、利用量を同じ解析結果から取り出します。
- **文章の整形。** 引用・コード・URL・パス等の保護範囲を処理ごとに一度だけ計算し、元の UTF-16 位置から編集します。語句の置換や補完の対象を増やしていません。
- **入力先の確認。** 入力先・選択範囲の取得を `InsertionTarget` へ分離し、外側から状態を書き換えない形に整理しました。
- **配布の検証。** ZIP 名とビルド番号を `Info.plist` から取得し、プルリクエストとリリースで同じアーカイブ検証を使用します。既存の v1.1.0 タグとダウンロードは変更しません。

## 修正した不具合

| 実在する処理 | 問題 | 修正 |
| --- | --- | --- |
| 利用統計・トークンの保存 | 書き込み失敗分が画面にだけ残り、次の保存成功時に消える | 未保存分を保持し、次の保存へ含める。削除成功時には未保存分も消去 |
| Gemini 失敗後の Apple 救済 | 古い Gemini の途中結果が、新しい Apple の救済結果より優先される | 実際に救済を担当している認識器の結果を優先 |
| Apple 認識の開始・終了 | キャンセル後の許可応答や遅延コールバックが状態を更新する | 明示的な状態遷移と取消確認を追加。締切後の救済起動と後始末も修正 |
| マイクの起動失敗 | 処理キューが残っている間に変換器・コールバックを破棄する | 通常停止と同じ排出処理へ統一し、失敗時の末尾送信を抑止 |
| Gemini バイナリ受信 | 不正な UTF-8 を空の JSON に置き換え、失敗を見逃す | 通信失敗として扱い、既存の救済・履歴保存へ接続 |
| 任意の音声再チェック | 応答サイズの制限が受信完了後にしか適用されない | 受信中に既存の上限を適用し、取消・異常時にセッションを終了 |
| 長い文章の直接入力 | 同期ループ中に同じ UI 実行系のキャンセル処理が進まない | 小さな送信バッチの間で制御を返し、送信を続ける前に取消と入力先を再確認 |
| 設定内検索・更新画面への移動 | 同じ結果の再選択が無視される、または移動先がない | 操作ごとのフォーカス要求と実在するアンカーを使用。ページ移動では古い要求を解除 |
| 処理時間の表示 | 実測値が確認待ちを含むのに、含まないと説明していた | 実際の測定区間に合わせて名称と説明を修正 |
| API キー削除 | Keychain の削除エラーでも成功と表示する | OS の結果を確認し、失敗時は下書きを保持してエラーを表示 |

## 画面・設定の変更区分

| 既存箇所 | 区分 | 既存文と完成文・動作 |
| --- | --- | --- |
| 設定→Gemini→API キーの削除結果 | 一部置換・失敗表示の新規追加 | 既存の「APIキーを削除しました」は成功時のみ表示。失敗時は「APIキーを削除できません：」に実際の OS エラー説明を続けて表示 |
| 設定内検索・更新画面への移動 | 処理の一部置換、ラベル変更なし | 同じ項目を押し直しても、その実在項目へ移動 |
| 専門用語の補助・文脈チェック | 変更なし | 独立チェック、全 OFF 時の無効化、録音開始時の設定スナップショットを維持 |
| 設定→一般→直近の処理時間 | 文言の一部置換 | 「録音停止から入力送信まで」→「録音停止から入力処理完了まで」。説明の「送信時間には相手アプリでの受理確認は含みません。」→「入力イベント送信後の確認待ち時間を含みます。」 |
| その他の設定ページ | 内部構造の一部置換 | 既存のラベル・保存キー・操作を維持 |

処理時間欄の導入文も、既存の「録音キーを押してからマイクが使えるまでと、録音終了後に入力を送信するまでの実測時間を表示します。」から「録音キーを押してからマイクが使えるまでと、録音停止から入力処理が終わるまでの実測時間を表示します。」へ置き換えました。

失敗表示は既存の折り返し可能な通知欄を使用します。新しい入力欄・文字数制限は追加していません。設定とメニューバーの状態は、引き続き同じコントローラを参照します。

## 公開時の検証

公開ワークフローは、公開ファイル監査、Python 回帰テスト、Swift Testing、portable self-test、Universal アプリのビルド、ZIP 展開後のメタデータ・ライセンス・アイコン・署名・両アーキテクチャ・SHA-256 がすべて成功した場合にのみ公開します。

追加した回帰テストでは、保存失敗からの復旧、未保存統計の削除、壊れた既存ファイルの保護、Apple 取消後の通知、Gemini フレーム解析、設定検索の再選択、混在する引用と Unicode パスを確認します。

**実際のマイク収録、Gemini 実通信、各アプリの編集欄への入力、画面レイアウトの実機確認は未実施です。** 入力先が必要な文章・選択範囲を公開しない場合など、反映を確認できない入力は自動再送しません。すべての不具合が解消したことを保証するリリースではありません。
