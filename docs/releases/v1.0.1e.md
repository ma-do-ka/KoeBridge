# KoeBridge v1.0.1e — メニューから更新センターへ確実に移動

2026-11-05 / macOS 15以降 / ソースコード版 / Build 24

## 修正内容

- **変更先：メニューバー「アップデートを確認…」 → 設定「情報」内の「アップデート」欄。**
- 初回に設定ウィンドウを生成する場合でも、更新画面への要求を失わないように修正。設定ビューの購読開始前に届いた要求は表示後に処理。
- 画面を「情報」へ切り替えるだけでなく、既存の「アップデート」セクションをスクロールして表示。
- 同じメニューを繰り返し選んでも更新欄に移動できるように修正。設定検索で使っている既存の実在セクションIDを共用。
- 既存の一般設定、音声入力、Gemini、macOSログイン時自動起動、トークン計測、APIキー、権限の扱いは**変更なし**。
- バージョンは1.0.1e / Build 24。既存v1.0.1dリリース・タグは変更しない。

## 更新機能の配布上の制約

本版も**ソースコードのみ**を配布します。GitHub Releasesの正式版確認・自動確認（1日上限）・更新コマンドのコピーは利用できますが、Developer ID署名・公証済みのインストーラーや安全なアーカイブ署名がないため、アプリの自動ダウンロード・自動インストールは引き続き**未対応**です。未対応のON/OFFは有効化しません。

## 反映手順

KoeBridgeをメニューバーから終了後、公式Git checkoutが `$HOME/KoeBridge` にあり、mainブランチに未保存変更がないことを確認して実行します。

```bash
cd "$HOME/KoeBridge"
bash scripts/update_from_release.sh v1.0.1e
```

スクリプトは、公式リモート・リリースタグ・Info.plist・ローカル変更なし・ff-only・ビルド・署名を確認してからアプリを更新します。Macのシステム権限を勝手に変更しません。

## CIで検証する内容と実機確認の限界

macOS Swift Testing、ポータブル自己テスト、Releaseビルド・署名、公開ファイル監査、更新スクリプト構文、更新先エントリが一意なことを検証します。メニューバー経由の初回表示、繰り返しスクロール、VoiceOver、実機Gemini通信は実ユーザーMacでの最終確認が必要です。
