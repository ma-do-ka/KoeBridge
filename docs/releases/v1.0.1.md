# KoeBridge v1.0.1

Source-code release for macOS 15+ (Apple Silicon) — 2026-11-05.

## Changes

- Accidental rapid double-presses and near-silent, very short recordings now exit with a subdued **「音声入力なし」** notice that clears in about 330 ms, rather than showing an error after transcription finalization.
- Recognized speech, longer recordings and actual microphone/audio errors continue through the existing finalization, safety, history and failure-handling paths. No automatic text entry occurs on an empty tap.
- Colorful settings sidebar, clear current-page identity, higher-contrast cards, scrolling hints and vertically aligned controls.
- Inline refresh feedback for macOS permissions and local usage statistics with Gemini/Apple usage metadata.
- New macOS application icon included in the source and built app bundle.
- Reduced latency in the voice input and finalization feedback without weakening focus protection.

## Install / update

This release contains **source archives**, not a notarized or universally installable macOS app. Build on your Mac with Swift / Xcode tools and a stable code-signing identity. Quit KoeBridge from the menu bar first.

```bash
cd ~/KoeBridge
git switch main
git pull --ff-only origin main
bash scripts/verify_and_build.sh --open
```

The built app is `~/KoeBridge/dist/KoeBridge.app`. If the checkout is elsewhere, run the script in that directory instead. On a first-time install, follow [README.md](../../README.md). Do **not** use `scripts/publish_to_github.sh` to update an existing repository.

## Test scope and limitations

- The GitHub Actions macOS CI executes Swift unit tests, portable core tests, Release compilation, application bundle and code-signing checks before this release is published.
- macOS microphone hardware, speech permissions, real Gemini API traffic, actual editor text insertion and every possible keyboard timing are **not** verified by headless CI.
- A brief but audible short utterance may still go through recognition; the short-tap filter is intentionally conservative.
- Google API errors (including dashboard 409 counts) are not suppressed by this UI improvement.
- The app is independent of Google and Apple and does not include an API key. MIT license.
