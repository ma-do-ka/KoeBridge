# KoeBridge v1.1.0 — 連続入力と考えながらの音声入力

2026-11-06 / macOS 15以降 / Build 26

## ダウンロード

`KoeBridge-v1.1.0-macOS-universal-development.zip` はApple Silicon・Intel共通の開発版アプリです。`SHA256SUMS.txt` でダウンロードのSHA-256を照合できます。

**アドホック署名の開発版です。Developer ID署名・Apple公証はありません。** KoeBridgeを終了し、既存アプリを退避してから展開・置換してください。macOSの起動確認やマイク・アクセシビリティなどの再許可が必要になる場合があります。公証済みの自動更新機能は提供していません。ソースから手元の継続した証明書でビルドする従来の方法も使えます。

## 変更内容

- **連続録音後の入力位置。** Aの確定直後にBを録音したとき、A自身の入力で動いたカーソルをBの手動移動と誤判定する経路を修正。結果は録音順に配送し、Aの入力先への反映を確認してから、対応する後続の入力位置だけ更新します。確認できない入力を盲目的に再送しません。
- **考える間の扱い。** Gemini Liveの自動発話区切りを、録音開始・停止に対応する `activityStart` / `activityEnd` へ変更。自然な間だけでは終了信号を送りません。末尾の音声を送ってから終了します。文字起こし専用モデルの終了通知にも対応し、正常な終了を余計に待つ経路を修正しました。句読点や聞き取りが常に正しくなる保証ではありません。
- **専門用語の補助。** 設定→Gemini→文字起こしの調整に「登録した用語を使う」「開発・ITの用語を使う」の独立チェックを追加。両方OFFなら候補を送りません。登録文は保持し、スタイル変更ではチェックを切り替えません。新規インストールは両方OFF、旧設定は最初の起動時に従来の有効な用語選択を引き継ぎます。
- **文脈チェック。** 「文章のつながりと句読点を確認する」「音声を再認識して照合する」を独立チェック化。両方OFFなら追加処理なし。文章チェックは「という。こと」等の限られた区切りをMac内で補正し、語句を言い換えません。引用・コード・URL・パスは保持します。
- **任意の音声照合。** Geminiで確定した同じ録音を最大1回再認識します。タイミングは「疑わしい箇所があるとき」または「毎回」のどちらかを選択。追加のAPI料金と待ち時間が発生します。語句が一致しても、文章チェックをOFFにしていれば句読点を変更しません。語句・数値等に違いがある場合は自動入力せず、履歴で両方を確認・コピーできます。
- **上限と失敗時の動作。** 追加通信は最大6秒、停止からの認識・追加チェック全体は15秒。音声照合はPCM 14,000,000バイト（約7分17秒）までで、長い録音を切り捨てて照合しません。時間・サイズ・通信の条件を満たさない場合は、初回の確定文を使い「追加チェック未完了」を記録します。Apple認識では追加チェックを実行しません。
- **入力と保存の表示。** 入力反映を確認、イベントを送信したが受理未確認、カーソル移動、先行入力未確認、権限不足、チェック差異を区別して履歴へ記録します。単に「入力先=ok」と出して理由が分からなくなる表示を置き換えました。直近の履歴メニューにも「要確認・元の文」「入力要確認」を表示し、コピーする文章を明確にします。
- **末尾の欠落防止。** Appleの認識が音声の途中で終了した場合、前半だけを完成文として自動入力しません。50秒を超える音声をAppleで一括救済する経路も明示的に停止し、取得済みの途中結果を残します。
- **利用統計。** 音声照合を通常のLive認識と区別して記録。概算スクリプトは再チェックの回数・音声分数を表示しますが、Liveの単価を当てはめて金額を混算しません。

## 既存箇所への変更区分

| 実在する箇所 | 区分 | 変更 |
| --- | --- | --- |
| 設定→Gemini→文字起こしの調整 | 新規追加・一部置換 | 独立チェックと、その有効範囲・追加通信の説明を追加 |
| 「固有名詞・専門用語を登録」の説明 | 一部置換 | スタイルで辞書を追加する説明を、個別チェック・登録順優先・最大100語の説明へ変更 |
| 一般/Geminiの文字起こしスタイル | 説明の一部置換 | 逐語・読みやすく・AIエージェント指示の選択は維持。補助の自動ONを廃止 |
| 認識履歴 | 新規追加・一部置換 | 配送理由と、追加チェックの原文・比較候補を表示 |
| 情報→自動アップデートの説明 | 一部置換 | 開発版の手動配布と、公証済み自動更新が未提供であることを明記 |

固定の入力文字数制限を追加していません。既存のスクロール可能な設定画面内に配置し、説明は折り返します。用語は登録順を優先し、API送信分は2種類を合わせて最大100語です。

## 検証範囲

公開ワークフローは、公開ファイル監査、Python回帰テスト、Swift Testing、portable self-test、macOSアプリのUniversalビルド、コード署名の整合性、ZIP展開後の署名・両アーキテクチャ・SHA-256の検証が成功した場合にのみReleaseを公開します。

**ユーザーのMacでのマイク収録、Gemini実通信、Chrome・Electron等の各編集欄への入力、画面レイアウトの実機確認は未実施です。** 入力欄が必要な文字列・選択位置を公開しない場合、先行入力の安全な引継ぎを確認できず、後続は履歴保存になることがあります。すべてのアプリに対応したことや、すべての不具合がなくなったことを表明するリリースではありません。

Geminiから録音終了に対応する完了通知が届かない場合は、最終セグメントだけを録音全体の完了と推測せず、待機上限後に救済認識または途中結果の保存へ進みます。実サービスでの完了通知のタイミングは、上記の実機確認の対象です。
