# KoeBridge v1.1.4b — Bluetooth準備・マイク選択・アプリ内更新（ソース Build 33）

**インストール用アプリZIPは未作成・未公開です。** 公開済みv1.1.4 / Build 31のZIPには、この変更は含まれません。mainのソース更新を配布アプリの更新と混同しないでください。

## Build 32から引き継ぐ修正

マイク開始APIの成功だけで録音中とせず、実際のPCM継続到着を確認します。初回準備失敗は1操作内で最大4試行。キャンセル後の復活防止、入力形式変更・音声途絶の検出、重複停止の待ち合わせ、古い音声バッファの誤判定防止を含みます。無音対策と入力先保護を維持します。

## Build 33の追加ソース

「音声入力」の「文字起こしの方法」と「録音の開始・終了キー」の間に「使用するマイク」を追加。初期値は「システム設定に従う」。明示選択した機器だけをKoeBridgeで使い、Mac全体の入力設定は変更しません。指定機器の未接続時は別機器に切り替えません。

更新画面から、Sparkleによる署名検証付きの取得・インストール・再起動を呼び出す処理を追加。署名用公開鍵が未設定のビルドでは無効です。現在公開鍵の登録と署名付き配布物の公開は未完了であり、今すぐボタンから更新できるという意味ではありません。

表示ラベルは1.1.4b、数値版は1.1.4、内部ビルドは33。先に案内した固定コミット `cacf80038ae0f334e280445aebe4d584f47b3bfd` のコマンドはBuild 32を作り、この追加機能は含みません。

## 検証と残作業

Linuxの限定Swiftテスト99件、フィード構造のPythonテスト16件、macOS用Swift9ファイルの構文解析を実施。macOS SDKでのビルド・実機録音・画面表示・署名付き更新の実行は未検証です。GitHub Actionsは使用しません。

動画の一時停止・再開、動画内の声と本人の声の識別は未実装。ヘッドセット症状の解消を実機確認したという報告ではありません。
