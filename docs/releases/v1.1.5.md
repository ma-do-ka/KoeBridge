## 実際にコピーされるコマンド

生成元は `SourceUpdateTarget.command`。公式mainを確認した時点のコミットで固定するため、その後mainが進んでも別の版へ勝手に変わりません。存在しない `v1.1.5` タグやリリースを参照しません。

`~/KoeBridge` がなければ新しいGitチェックアウトを作ります。既存の場合は公式origin・main・変更なしを確認し、前進更新だけを許可します。別ブランチ、未保存変更、未追跡ファイル、異なるorigin、巻き戻し、起動中のKoeBridgeは停止条件です。削除・強制reset・自動stashをしません。ビルド前後で版・ビルド番号を照合し、成功後に `~/KoeBridge/dist/KoeBridge.app` を起動します。

**別の場所（例：/Applications）にあるアプリは置き換えません。** ソース更新を使う場合、以後は表示されたdistのアプリを起動してください。既存のビルド処理が旧distアプリの退避・置換を担当します。

MacのSwift / Command Line Toolsと、既存のビルドスクリプトに適合する署名環境が必要です。証明書がない場合に、コマンドが勝手にアドホック署名へ切り替えたり、macOSの保護を無効化したりすることはありません。ユーザーが手動実行するソースビルドであり、Sparkleの署名付きバイナリ更新とは別です。

## 検証と未完了

- Linux / Swift 6.2.1：新規ポリシーの24 XCTest成功。比較に使用した既存ReleaseUpdatePolicyはGit blob SHAを照合。
- Swiftが実際に生成したコマンドを使った13 Python実行テスト成功。実Gitのローカルfixtureと、macOS・ビルド・起動の偽ツールを使用。ネットワーク・実署名・実アプリは使用していません。
- 生成コマンドのbash構文解析、macOS Swift 2ファイルのOSガードを外した構文解析、plist解析、追加分を除いた元allowlist・Info.plistのSHA照合を実施。
- **未検証：macOS SDKでの型検査・リンク、画面の実描画、マイク実機、実際のクリップボード、署名・アプリ置換・再起動。** 構文解析をMac全体ビルド成功とは扱いません。
- GitHub Actionsは使用しません。公開鍵・署名付きフィード・配布ZIPの準備は未完了のままです。署名がない状態で「ダウンロードしてインストール」を有効にする変更はありません。

旧版の実行ファイルには今回の変更は入りません。最初の1回はmainの新しいソースを手動ビルドする必要があります。以後、この版の「情報 → アップデートを確認… → 更新コマンドをコピー」から、確認済みコミットのコマンドを取得できます。
